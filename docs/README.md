# agnsteps -- AGN light curves with "steps"
Specifically, a study of mostly BL Lac blazars with only one or two apparent transitions or "steps" during the 16-year Fermi mission.
Of the 1468 classified as BL Lacs, 253 have this characteristic.

See [readme.ipynb](../readme.ipynb)
